# Probing Human Event Perception through Large Language Models with Sparse Autoencoders

## Overview
This project explores whether Large Language Models (LLMs) can replicate human incremental sentence processing behaviors on event segmentation. Then by anlayzing the aligned model representation with SAE, we aim to provide a mechanistic interpretation of how humans perceive event boundaries.

### Key Objectives
1. Use LLMs to imitate human experiments of event segmentation in story listening tasks.
2. Investigate the better setting in models which aligns most with human behavior.
3. Analyze LLM's behavior and underlying representations, and figure out the what contributes to the event perception by humans.

## Data Sources
The study leverages human segmentation data and GPT-2-based predictions from three narrative datasets:
- **Monkey in the Middle** (newly acquired segmentation data)
- **Pieman**
- **Tunnel Under the World**
